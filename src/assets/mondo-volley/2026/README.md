# Foto Mondo Volley 2026

Copia in questa cartella le foto dell'edizione 2026 (formati supportati: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`).

Le foto vengono rilevate automaticamente in fase di build: compaiono nella galleria di `/mondo-volley/foto` e le prime quattro nell'anteprima della pagina principale, in ordine alfabetico di nome file. Non serve toccare il codice.

Non preoccuparti del peso: Astro le ridimensiona e le converte in WebP automaticamente. Evita solo nomi file con caratteri strani (spazi ok, meglio trattini).

Per le edizioni future basta creare una cartella gemella, ad esempio `src/assets/mondo-volley/2027/`.

Il podio e il link ai risultati di ogni edizione si compilano in `src/data/mondo-volley-edizioni.json`.
